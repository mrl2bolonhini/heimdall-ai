# Referência do comando heimdall. Uma seção por comando, no formato:
#   @ comando | resumo de uma linha
#   texto livre
#   Opções:
#     -x, --longa  <duas ou mais espaços>  o que faz
#   Exemplos:
#     heimdall comando --opção
# É lida pelo heimdall.zsh (heimdall COMANDO --help e heimdall help) e por gerar_docs.py (página Comando heimdall do site e heimdall help --doc).
# Toda opção aceita também a forma curta de uma letra; -h e --help existem em todos os comandos.

@ up | Sobe todo o ecossistema
Roda o subir.sh: sobe os serviços, guarda o log da subida e avisa quando tudo estiver no ar. Sem opções sobe com --webui --terminal.
Opções:
  -w, --webui      sobe também o Open WebUI (chat, porta 3000)
  -t, --terminal   sobe o Open Terminal (porta 8002)
  -n, --n8n        sobe o n8n (automações, porta 5678)
  -a, --agent      sobe o agente do Mac (ponte do n8n com Notas e Lembretes, porta 8003)
  -i, --ingest     indexa em knowledge/ só o que mudou antes de subir o LiteLLM
  -d, --docling    sobe o Docling (leitura de PDFs com OCR, porta 5001)
  -u, --update     atualiza as imagens Docker (SearXNG, Qdrant e Open WebUI), com backup
  -h, --help       mostra esta ajuda
Exemplos:
  heimdall up
  heimdall up --webui --terminal --n8n
  heimdall up -w -t -n -a

@ restart | Encerra a subida atual e sobe de novo
Faz o mesmo que up, depois de encerrar o que estava em andamento. Aceita as mesmas opções do up.
Opções:
  -w, --webui      sobe também o Open WebUI
  -t, --terminal   sobe o Open Terminal
  -n, --n8n        sobe o n8n
  -a, --agent      sobe o agente do Mac
  -i, --ingest     indexa knowledge/ antes de subir
  -d, --docling    sobe o Docling
  -u, --update     atualiza as imagens Docker
  -h, --help       mostra esta ajuda
Exemplos:
  heimdall restart
  heimdall restart --webui --terminal --n8n

@ stop | Encerra os serviços do Mac
Encerra o que escuta nas portas 8000 a 8004, 8010 a 8014, 8099 (documento da ajuda) e 9000 (MCP, agente, Cloud, Notas, News, painel de saúde e LiteLLM). Os contêineres do Docker continuam rodando.
Opções:
  -h, --help       mostra esta ajuda
Exemplos:
  heimdall stop

@ health | Painel de saúde e relatórios no terminal
Sem opção abre o painel de saúde no navegador (porta 8013). Com --open abre uma página dele. Com qualquer outra opção, roda o relatório no terminal. Nada aqui é diagnóstico.
Opções:
  -L, --local          abre o endereço deste Mac (http://localhost, senha e código de 6 dígitos) em vez do endereço público, que passa pelo Cloudflare Access e pelo Authenticator
  -o, --open PÁGINA    abre uma página do painel: anomalies, today, week, sleep, activity, recovery, heart, workouts, events, diary, data
  -t, --today          o que já chegou de hoje
  -n, --now            os últimos 7 dias contra a média dos 90 anteriores
  -w, --weekly         o relatório da semana
  -a, --anomalies [AAAA-MM-DD]   o que saiu do seu normal (cada medida contra os 30 dias anteriores)
  -r, --report [DIAS]  análise geral (padrão 30 dias)
  -s, --sleep [DIAS]   sono (padrão 90 dias)
  -A, --activity [DIAS]  atividade: passos, exercício e esforço (padrão 90)
  -R, --recovery [DIAS]  recuperação: HRV e pulso em repouso (padrão 180)
  -T, --trends [DIAS]  tendências (padrão 90)
  -W, --workouts [DIAS]  treinos (padrão 30)
  -e, --ecg [DIAS]     ECG (padrão 365)
  -f, --fc [DIAS]      frequência cardíaca (padrão 14)
  -i, --import ARQUIVO   importa o export.zip do app Saúde (pode repetir sem duplicar)
  -N, --import-n8n     copia para o banco o histórico de saúde que estava no n8n
  -h, --help           mostra esta ajuda
Exemplos:
  heimdall health
  heimdall health --open anomalies
  heimdall health --today
  heimdall health --anomalies 2026-11-10
  heimdall health -r 60

  -p, --play JOGO      abre direto um jogo: 2048, arqueiro, bacara, naval, blackjack, cacaniqueis, minas, caverna, cincoletras, orion, aventura, forca, gramado, velha, labirinto, relogios, numero, paciencia, caribenho, poker, roleta, senha, sonar, sudoku, templo, escolhas, xadrez

@ finance | Heimdall Finance, suas finanças em páginas de texto
Abre o painel financeiro no navegador (porta 8016; de fora, finance.heimdall-ai.tech). Você importa extratos do banco e faturas do cartão em OFX, CSV ou PDF; o painel identifica o banco (Nubank, Itaú, Mercado Pago) e se é conta ou cartão, classifica os gastos por categoria com regras que você ajusta (ao corrigir uma categoria, a regra nasce sozinha), mostra o resumo do mês com variação sobre o mês anterior, os maiores gastos, a evolução mês a mês e avisa quando uma categoria dispara. Tudo em tabelas para leitor de tela. Os dados ficam só no Mac, na pasta dados_financas (fora do git), e nunca vão para a Cloudflare nem para modelo de fora. Usa o mesmo login do Cloud.
PDF: o texto é lido e o total do documento (por exemplo "Total da fatura") é conferido com a soma dos lançamentos. Só o que confere é importado sozinho; o resto vai para revisar. A pasta de entrada (dados_financas/entrada) é vigiada a cada minuto: solte lá os arquivos; o que importar vai para importados e o que deixar dúvida vai para revisar, com o motivo. Arquivo duplicado não é importado e é apagado; o motivo some quando o arquivo é revisado.
Opções:
  -L, --local          abre o endereço deste Mac (http://localhost, senha e código de 6 dígitos) em vez do endereço público, que passa pelo Cloudflare Access e pelo Authenticator
  -h, --help           mostra esta ajuda
  -o, --open           abre o painel no navegador (é o padrão sem opções)
  -f, --folder         abre a pasta de entrada no Finder e lista os arquivos para revisar
  -i, --inspect ARQ    mostra só a estrutura do arquivo (letras viram x, números viram 9) e copia para a área de transferência; serve para me mostrar o layout do seu banco sem enviar dados
  -x, --explain ARQ    diagnóstico anônimo de PDF: mostra, linha por linha, o que o leitor fez (lançamento, saldo, ignorada, sem data) e quantos saldos fecham em cada jeito de conferir; copia para a área de transferência
  -l, --lines N        com --inspect, quantas linhas mostrar (padrão 150)
  -p, --preview ARQ    mostra o que seria importado, com a conferência do total, sem gravar
  -m, --import ARQ     importa um arquivo (OFX, CSV ou PDF)
  -a, --account NOME   com --import, o nome da conta ou do cartão (sem isso, usa o que for identificado)
  -F, --force          com --import, importa o PDF mesmo que o total não confira (só depois de revisar)
  -b, --inbox          importa agora o que estiver na pasta de entrada, sem esperar o minuto
  -v, --values         com --explain, mostra também os valores em reais das linhas lidas como lançamento (a descrição continua mascarada); use quando o total não confere e for preciso achar qual lançamento tem o sinal errado
  -B, --bill ARQ|CÓDIGO lê um boleto (PDF, linha digitável de 47 ou 48 dígitos, código de barras de 44 dígitos ou Pix copia e cola, entre aspas), confere os dígitos e guarda como conta a pagar; nunca paga nada. PDF de boleto solto na pasta de entrada também é registrado
  -D, --bills          lista os boletos em aberto, com valor, vencimento e o total por pessoa
  -E, --read-email     lê agora o Gmail (somente leitura, só Caixa de entrada) atrás de boletos e Pix dos últimos 7 dias (ou de N dias com --days N, até 365), mostra quantas mensagens a busca trouxe e por que cada uma foi descartada, por exemplo só link, PDF escaneado ou dígitos que não conferem e registra como contas a pagar; o painel já repete isso a cada 15 minutos. Boleto de remetente não autenticado entra com aviso de possível golpe. Precisa da senha de aplicativo do Gmail no .env (a mesma do monitor de e-mails oficiais); HEIMDALL_FINANCE_EMAIL=0 desliga a leitura automática. Boleto que o e-mail diz estar em débito automático ou cartão, ou que o histórico mostra pago, vira Já programado e sai das contas a pagar (botão É para pagar mesmo desfaz)
  -S, --sync           baixa sozinho as contas e transações dos bancos conectados no Meu Pluggy (plano pessoal gratuito, somente leitura; os dados passam pelos servidores do Pluggy) e importa no Finance, sem duplicar. O painel repete isso a cada 6 horas; HEIMDALL_FINANCE_PLUGGY=0 desliga. Precisa das chaves no .env
  --save-pluggy ID|segredo|itens  grava no .env a chave que você acabou de copiar (Client ID, Client Secret ou o id de um banco conectado; repetir com outro id acrescenta o banco, sem apagar os anteriores; também aceita o endereço da página Demo com ?item=, de onde tira só o id do item), lendo a área de transferência sem mostrar o valor; depois do segredo, esvazia a área de transferência
  --since AAAA-MM-DD   com --sync, busca desde essa data (o Meu Pluggy guarda até 12 meses). Sem isso, começa no dia seguinte ao último extrato importado da conta, ou 90 dias atrás
  --list               com --sync, mostra as contas dos bancos e o nome de cada uma no Finance
  --name N=NOME        com --sync, dá o nome N da lista a uma conta
  --diagnose-card NOME mostra como o Pluggy devolve as transações e faturas de um cartão (parcelas, datas de compra, fatura de cada uma), para conferir parcelados
  --fixed-installment NOME=VALOR:PARCELA/TOTAL cadastra uma parcela que o banco cobra mas não lista (ex.: mercado=176,42:14/21, a parcela que cai na fatura em aberto agora); o programa avança a parcela a cada fatura e para sozinho na última; mercado=remover tira
  --closing NOME=REGRA guarda quando fecha a fatura de um cartão: um dia do mês (itau=27) ou vencimento:dias antes (itau=1:7); com ele, --balance calcula a fatura em aberto pelas compras do ciclo
  --balance            mostra o saldo de cada conta e a fatura de cada cartão na última leitura do banco, com os totais
  --latest             mostra os últimos lançamentos (use --limit N, --account PEDAÇO_DO_NOME, --month AAAA-MM, --search TEXTO, --category NOME)
  --summary            resumo do mês (entradas, gastos, onde mais gastou, maiores gastos); use --month AAAA-MM para outro mês
  --simulate           com --sync e --since, só mostra até onde o Pluggy devolve histórico de cada conta, sem gravar nada
  --redo-from-pluggy   mostra e, com --force, apaga os lançamentos das contas do Pluggy (inclusive de extrato) depois de copiar o banco, e relê tudo pelo Pluggy desde --since (padrão 2024-01-01)
  --dedupe             mostra (e, com --force, apaga) lançamentos do Pluggy que repetem extrato ou fatura já importados (mesma conta, dia e valor)
  --standardize-names  renomeia sozinho, com o histórico, as contas do Pluggy para o padrão (Banco conta corrente, Banco cartão de crédito), sem digitar nomes
  --rename-account "ATUAL=NOVO"  troca o nome de uma conta já importada por extrato, com todo o histórico (faça antes da primeira sincronização)
  -P, --person NOME    com --bill, de quem é o boleto (por exemplo, a noiva ou a filha); a pessoa é cadastrada na hora. Só o nome, nunca CPF. Sem isso, o Heimdall tenta achar o pagador no PDF
  -r, --retry          devolve tudo de revisar para a entrada e importa de novo (use depois de uma atualização do leitor); o motivo antigo some
Exemplos:
  heimdall finance
  heimdall finance --folder
  heimdall finance --inspect ~/Downloads/fatura.pdf
  heimdall finance --preview ~/Downloads/fatura.pdf
  heimdall finance --bill ~/Downloads/boleto.pdf
  heimdall finance --bills
  heimdall finance --import ~/Downloads/extrato.ofx --account "Itaú conta"
  heimdall logs --service finance

  -h, --help           mostra esta ajuda

Grava no .env a chave que liga a reserva de resumos no Workers AI e a leitura de páginas com navegador do News.
Opções:
  -s, --set            grava a chave (é o padrão)
  -t, --test           testa a chave gravada, mostrando a resposta da Cloudflare
  -h, --help           mostra esta ajuda
Exemplos:
  heimdall cloudflare
  heimdall cloudflare --test

@ mcp | Servidor MCP de dados
Confere se o servidor MCP de dados (porta 8004) está no ar e se o Open WebUI, no Docker, consegue alcançá-lo.
Opções:
  -v, --verify         faz a conferência (é o padrão)
  -h, --help           mostra esta ajuda
Exemplos:
  heimdall mcp

@ flows | Instala fluxos no n8n
Importa fluxos para o n8n, que precisa estar no ar. Sem opção instala as automações avançadas.
Opções:
  -a, --advanced       automações avançadas (saúde, GitOps, triagem, resumos): instalar_automacoes_avancadas.sh
  -b, --basic          fluxos básicos da pasta n8n_flows/ (resumo da AWS, estudo, vigia de versões)
  -p, --privacy        monitor de privacidade diário
  -e, --email          vigia de e-mails oficiais
  -h, --help           mostra esta ajuda
Exemplos:
  heimdall flows
  heimdall flows --privacy

@ hook | GitOps num repositório
Instala ou remove o gancho pre-push que avisa o n8n a cada git push de um repositório local.
Opções:
  -i, --install REPOSITÓRIO   instala o gancho (é o padrão quando só há o caminho)
  -r, --remove REPOSITÓRIO    remove o gancho
  -h, --help           mostra esta ajuda
Exemplos:
  heimdall hook ~/projetos/meu-repo
  heimdall hook --remove ~/projetos/meu-repo

@ update | Traz as novidades do GitHub
Faz git pull --ff-only da branch atual do projeto e diz se precisa reiniciar ou reinstalar fluxos. Depois recarrega os comandos do heimdall no próprio terminal, então não precisa dar source de novo.
Opções:
  -r, --restart        reinicia os serviços em seguida
  -h, --help           mostra esta ajuda
Exemplos:
  heimdall update
  heimdall update --restart

@ docs | Regenera o site e o README
Roda gerar_docs.py: gera docs/ e as tabelas do README a partir do código.
Opções:
  -b, --brand          regenera as imagens da marca (precisa de Playwright)
  -h, --help           mostra esta ajuda
Exemplos:
  heimdall docs

@ test | Testes do projeto
Sem opção lista os testes.
Opções:
  -l, --list           lista os testes
  -a, --all            roda todos os testes teste_*.py e diz quantos falharam
  -r, --run NOME       roda um teste (heimdall test --run anomalias roda teste_anomalias.py)
  -h, --help           mostra esta ajuda
Exemplos:
  heimdall test --list
  heimdall test --run anomalias
  heimdall test --all

@ dir | Pasta do projeto
Mostra o caminho da pasta do projeto (HEIMDALL_DIR).
Opções:
  -h, --help           mostra esta ajuda
Exemplos:
  heimdall dir

@ cd | Entra na pasta do projeto
Muda a pasta do seu terminal para a do projeto.
Opções:
  -h, --help           mostra esta ajuda
Exemplos:
  heimdall cd

@ help | Ajuda do comando heimdall
Sem argumentos lista os comandos. Com o nome de um comando mostra só as variações dele, o mesmo que heimdall COMANDO --help.
Opções:
  -d, --doc            abre no navegador o documento com todos os comandos e opções explicados (servido em http://localhost:8099 enquanto o terminal estiver aberto; o servidor sai com heimdall stop)
  -h, --help           mostra esta ajuda
Exemplos:
  heimdall help
  heimdall help health
  heimdall help --doc
