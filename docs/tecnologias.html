Tecnologias

O que foi usado

  • Ollama: Executa os modelos de linguagem no computador.
  • LiteLLM: Reúne os modelos em um único ponto de acesso e expõe os servidores MCP.
  • Open WebUI: Interface de chat.
  • Model Context Protocol (MCP): Padrão que liga o assistente a ferramentas externas.
  • FastMCP: Biblioteca Python que implementa os servidores MCP do projeto.
  • Qdrant: Base vetorial para a busca por significado.
  • SearXNG: Busca na web sem rastreamento.
  • n8n: Automações e agendamentos.
  • Bark: Aplicativo de notificações para o iPhone.
  • Docker: Contêineres dos serviços auxiliares.
  • Tailscale: Rede privada que liga o celular ao computador.
  • Cloudflare: Domínio, DNS e túnel de acesso ao chat.
  • GitHub e GitHub Pages: Código e esta documentação.
  • Python 3.12: Servidores MCP, agente do Mac, indexação e testes.
  • AppleScript e macOS: Integração com Notas, Calendário, Lembretes e voz.

Requisitos

  • Mac com chip Apple e 16 GB de memória ou mais (o projeto roda em um MacBook M2 Pro de 16 GB).
  • Docker Desktop, Ollama, Python 3.12 e, para o servidor de documentação da AWS, o uv.
  • Para os avisos: o aplicativo Bark no iPhone. Para o acesso remoto: Tailscale.
  • Pacotes Python no venv: fastmcp, litellm (com proxy), feedparser, psutil, pypdf, requests, starlette, pyyaml e youtube-transcript-api.
  • Para o modelo de embeddings: ollama pull nomic-embed-text.
