Cloud

O Heimdall Cloud é um painel web para usar o emulador de AWS (LocalStack, com o Moto como alternativa) pelo navegador. Serve para estudar engenharia de dados na AWS sem custo e sem depender de um console visual: as páginas são texto, títulos, tabelas e formulários simples, boas para leitor de tela.

Como entrar

  1. Endereço: cloud.heimdall-ai.tech. É de uso pessoal, não é aberto ao público.
  2. A entrada pede uma senha forte e um código de 6 dígitos, que o aplicativo Senhas da Apple gera e troca a cada 30 segundos.
  3. O painel só responde com o computador ligado e o sistema rodando. No próprio computador, o endereço é http://localhost:8010.

O que dá para fazer

  • S3: criar e apagar buckets, enviar, baixar e apagar arquivos.
  • Lambda: criar uma função a partir de código Python, executar com um evento e ver a resposta e o registro de saída.
  • Glue: bancos de dados, tabelas (a partir de uma pasta do S3 em CSV, JSON ou Parquet), crawlers e jobs.
  • Athena: consultas SQL sobre os arquivos do S3, com o resultado em tabela e o histórico das últimas consultas.
  • Console geral: qualquer operação de qualquer serviço (DynamoDB, SQS, SNS, Kinesis, IAM, CloudFormation e outros), com os parâmetros em JSON e exemplos prontos.

Do arquivo à consulta

  1. No S3, crie um bucket e envie um arquivo CSV para dentro de uma pasta.
  2. No Glue, crie um banco de dados.
  3. No Glue, crie uma tabela apontando para a pasta do S3, com as colunas e os tipos.
  4. No Athena, escolha o banco e rode um SELECT na tabela.

O roteiro completo, com exemplos, o teste do Lambda e a solução de problemas, está em LEIAME_cloud_roteiro.txt.

Segurança

  • O painel escuta só em 127.0.0.1. A porta do emulador nunca é exposta, porque ela não tem senha.
  • Entrada com senha (guardada só como hash PBKDF2) e código de 6 dígitos (TOTP), que não pode ser reaproveitado.
  • Limite de tentativas por endereço e global, com bloqueio de 15 minutos.
  • Sessão em cookie HttpOnly e SameSite=Strict, com validade, e token contra CSRF nos formulários.
  • Só atende os nomes de site permitidos, manda cabeçalhos de segurança e entrega os arquivos baixados sempre como anexo.
  • Executar funções Lambda dá ao emulador controle do Docker do computador. Por isso a entrada tem duas camadas, e a execução pode ser desligada com HEIMDALL_LOCALSTACK_DOCKER=0.

Configuração

  • Definir a senha e gerar o código de 6 dígitos: python3 heimdall_cloud.py --definir-senha
  • Gerar só um novo código: python3 heimdall_cloud.py --novo-codigo
  • Conferir se o painel está no ar: curl -s http://localhost:8010/saude
  • Testar o painel sem o LocalStack: python3 teste_cloud.py

O painel sobe sozinho com o sistema quando há senha e código no .env. Se o LocalStack recusar a licença, o sistema avisa e usa o Moto no lugar, onde Lambda, Glue e Athena são só simulados. Veja os comandos completos em Comandos e o histórico em Novidades.
