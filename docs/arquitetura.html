Arquitetura

Visão geral

O Heimdall-ai tem quatro camadas, da base para o topo.

  1. Modelos. O Ollama executa os modelos de linguagem no Mac (chip Apple, 16 GB de memória).
  2. Acesso único. O LiteLLM Proxy (porta 9000) expõe todos os modelos em uma API compatível com a da OpenAI e repassa os servidores MCP. Clientes como o Open WebUI e aplicativos de iPhone falam só com ele.
  3. Ferramentas. Dois servidores MCP em Python (portas 8000 e 8001) e o servidor de documentação da AWS dão ao modelo ferramentas: busca na web, leitura de páginas, arquivos, memória, documentos pessoais.
  4. Automações. O n8n agenda fluxos que usam os modelos e as ferramentas. O agente do Mac (porta 8003) liga o n8n, que roda em Docker, aos aplicativos do macOS. O Bark entrega os avisos no iPhone.

O caminho de uma pergunta no chat

  1. A pessoa escreve no Open WebUI (pelo navegador ou pelo celular, pela rede privada Tailscale).
  2. O Open WebUI envia ao LiteLLM, que encaminha ao Ollama o modelo escolhido.
  3. Se o modelo decide usar uma ferramenta, devolve uma chamada estruturada; o LiteLLM a executa no servidor MCP correspondente e devolve o resultado ao modelo.
  4. O modelo escreve a resposta final com o que a ferramenta trouxe.

O caminho de uma automação

  1. O n8n dispara um fluxo no horário (ou por um evento, como um git push).
  2. O fluxo busca dados (feeds, SearXNG, Qdrant, notas) e pede análises ao modelo pelo LiteLLM.
  3. O resultado vai para o app Notas, o Calendário ou os Lembretes, pelo agente do Mac, e um resumo chega ao iPhone pelo Bark.
  4. Se qualquer etapa falha, o fluxo de aviso de falha notifica; nenhuma automação falha em silêncio.

Os serviços de Docker escutam só no próprio computador. O acesso de fora passa pela rede privada Tailscale ou por túnel da Cloudflare com autenticação.

Princípios de privacidade e segurança

  • Dados pessoais ficam no Mac. Chaves e identificadores ficam no arquivo .env, com permissão restrita, e nunca no repositório.
  • Pastas privadas são intocáveis. Notas de pastas marcadas como privadas nunca são lidas, indexadas nem analisadas. Se a verificação falhar, nenhuma nota é entregue.
  • O agente só escreve onde deve. Grava apenas nas pastas do próprio Heimdall e nas pastas de temas de estudo.
  • Autenticidade antes de confiança. O vigia de e-mail só trata como oficial o remetente que o Gmail confirmou, e nunca segue links.
  • Sem falha silenciosa. Quando uma fonte não responde, o aviso diz isso e nunca finge que não há novidade.
  • Entradas externas são dados, não ordens. Textos de páginas, e-mails e documentos passados ao modelo são tratados como conteúdo não confiável.
