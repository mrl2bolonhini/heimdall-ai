Heimdall Design

O padrão de interface é o mesmo em todos os sites do Heimdall (Cloud, Notas, News, Saúde, Jogos e Finance), para você nunca ter de adivinhar como algo funciona. Ele foi pensado para leitor de tela e teclado. O código compartilhado está em heimdall_design.py e heimdall_paginacao.py, e o teste teste_design.py impede que uma ação volte a ser link.

Link lê, botão age

  1. Link leva a outro lugar para ler: o menu, "Voltar", o nome de um item em lista ou tabela (um bucket, uma nota, um jogo, uma categoria), "Leia mais" e os links dentro de um texto.
  2. Botão faz uma ação ou comando, mesmo quando o resultado é abrir outra página: baixar, atualizar, continuar, confirmar, alterar, classificar, importar, trocar a visão ou o período, paginar, "Ver todos..." e "Ver resultado".
  3. Uma ação que só consulta é um formulário com um botão. Funciona sem JavaScript e o leitor de tela anuncia como botão.
  4. Botões repetidos numa lista levam o nome do item para o leitor de tela diferenciar, por exemplo "Alterar categoria de Mercado".
  5. A opção escolhida num grupo de botões é marcada com aria-current.
  6. Exceção única: quando o destino é um esquema de aplicativo (por exemplo, o app Atalhos do iPhone), o botão é um link com role="button", porque um formulário não abre esse tipo de endereço de forma confiável.

Paginação

Sempre em botões, num só formulário: Página anterior, os números das páginas (a atual marcada e dita "atual"), Próxima página e Última página. Quem usa: News, Notas e Finance.

Estrutura de toda página

  • Primeiro um link "Pular para o conteúdo", depois o menu principal numa região com nome ("Principal").
  • Um só título principal por página, com os subtítulos em ordem.
  • Tabelas sempre com legenda (caption) e cabeçalhos de coluna (scope="col").
  • Campos de formulário sempre com rótulo; avisos e erros com role="status" ou role="alert".
  • Claro e escuro automáticos, com contraste alto e foco bem visível.

Ao criar uma página nova

  1. Importe heimdall_design e use design.botao(rota, rótulo, parâmetros) para qualquer ação de consulta.
  2. Use heimdall_paginacao para listas longas.
  3. Rode heimdall test --run design. Se alguma ação ainda for link, o teste mostra a linha.
