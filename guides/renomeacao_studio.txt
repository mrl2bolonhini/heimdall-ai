Renomeação de Heimdall para Studio: plano em fases

Decisões (26/11/2026): empresa StudioLibre; apps e telas Studio Health, Studio Finance, Studio Games, Studio Memory etc.; comando `studio`; variáveis STUDIO_; domínio studiolibre.io. Repositório: studiolibre/heimdall-ai (o nome do repositório ainda será renomeado na fase 2).

Princípio: nada que roda hoje no Mac pode quebrar. Cada fase se desliga ou volta atrás, e o nome antigo continua funcionando como alternativa durante a transição.

Fase 1 (feita): endereço do GitHub trocado de mrl2bolonhini para studiolibre no README, nos guias e no gerador do site; site regenerado.
Fase 2: renomear o repositório no GitHub; atualizar o endereço remoto das cópias locais (git remote set-url origin); GitHub Pages: o registro CNAME www passa a apontar para studiolibre.github.io (hoje aponta para o usuário antigo).
Fase 3 (código, em blocos pequenos, com testes a cada bloco):
 1. Texto visível: Heimdall vira Studio nos nomes de tela, menu, ajuda, FAQ, notificações e documentação (gerar_docs.py, README, CHANGELOG). Os nomes de serviço passam a Studio Health etc.
 2. Variáveis: STUDIO_* passa a valer, e HEIMDALL_* continua lida como alternativa (uma função única de leitura; aviso de uso do nome antigo no diagnóstico).
 3. Comando: `studio` no heimdall.zsh, com `heimdall` como apelido temporário; instalador atualiza o ~/.zshrc.
 4. Arquivos e módulos: heimdall_*.py, start_heimdall.sh e macapp/Heimdall.swift. Os LaunchAgents apontam para subir.sh, start_heimdall.sh e heimdall.zsh: mover só com reinstalação dos agentes e deixar os nomes antigos como redirecionadores.
 5. Pastas de dados do Mac: migração automática em heimdall_pastas.py, sem apagar dados. Nome do contêiner Docker e dos bancos só com cópia de volta antes.
Fase 4 (Cloudflare, com limite de gasto e plano de volta): subdomínios em studiolibre.io (health, finance, games, memory etc.); os endereços de heimdall-ai.tech redirecionam; túnel, aplicativos do Access, roteamento de e-mail (suporte@), bucket do R2 e Workers; deploy da continuidade.
Fase 5: página Marca, CHANGELOG, CLAUDE.md e guias; mensagem de despedida do nome antigo.

Fora do escopo desta renomeação: logomarca e cores (decisão de design à parte); consulta ao INPI (com o usuário).
